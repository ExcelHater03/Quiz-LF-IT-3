1. Der Begriff „Algorithmus“
MerksatzEin Algorithmus ist eine eindeutige, endliche Folge von Anweisungen (Handlungsvorschrift) zur Lösung eines Problems bzw. einer ganzen Klasse von Problemen.
  • Ablauf: Eingabe → Verarbeitung → Ausgabe (EVA-Prinzip).
  • Alltagsbeispiele: Kochrezept, Wegbeschreibung, Bedienungsanleitung, Sortieren einer Liste, schriftliche Division.
  • Darstellungsformen: Programmablaufplan (PAP), Struktogramm (Nassi-Shneiderman), Pseudocode oder direkt als Programmcode.
  • Ein Algorithmus ist noch kein Programm: Das Programm ist die Umsetzung des Algorithmus in einer Programmiersprache.
2. Eigenschaften von Algorithmen
EigenschaftBedeutung
EindeutigkeitJeder Schritt ist klar und unmissverständlich beschrieben.
Endlichkeit (Terminierung)Der Algorithmus besteht aus endlich vielen Schritten und hält nach endlicher Zeit an.
AusführbarkeitJeder Einzelschritt kann tatsächlich durchgeführt werden.
DeterminiertheitGleiche Eingabe ⇒ immer das gleiche Ergebnis.
DeterminismusGleiche Eingabe ⇒ immer der gleiche Ablauf (Zwischenschritte).
AllgemeingültigkeitLöst nicht nur ein Einzelproblem, sondern eine ganze Problemklasse.
Die Begriffe unterscheiden sich je nach Lehrbuch leicht (manchmal auch „Korrektheit“, „Effizienz“, „Vollständigkeit“). Lerne vor allem die Wörter aus deinem Unterricht / Skript.
3. Klasse und Objekt
MerksatzDie Klasse ist der Bauplan (Schablone, Vorlage). Ein Objekt ist eine konkrete Instanz (Ausprägung, Exemplar) dieser Klasse.
KlasseObjekt
Was ist das?Bauplan / TypKonkretes Exemplar im Speicher
AnzahlWird einmal definiertBeliebig viele pro Klasse
EnthältAttribute (Eigenschaften) und Methoden (Verhalten) als VorgabeKonkrete Werte der Attribute
BeispielAutoder rote Golf von Max
public class Auto {                 // Klasse = Bauplan
    private String farbe;              // Attribut
    public void fahren() { ... }       // Methode
}

Auto a1 = new Auto();   // Objekt 1 (Instanz)
Auto a2 = new Auto();   // Objekt 2 – gleiche Klasse, eigener Zustand
  • Ein Objekt wird mit dem Schlüsselwort new erzeugt (Instanziierung); dabei läuft der Konstruktor.
  • Klasse = Typ, Objekt = Wert/Variable dieses Typs.
4. public, private und static
SchlüsselwortBedeutung
publicZugriff von überall – auch aus anderen Klassen.
privateZugriff nur innerhalb der eigenen Klasse. Grundlage der Kapselung (Information Hiding). Von außen nur über Getter/Setter.
staticGehört zur Klasse, nicht zu einem Objekt. Aufruf ohne new, z. B. Math.sqrt(9).
public class Konto {
    private double stand;                  // nur in Konto sichtbar
    private static int anzahl = 0;         // gehört der Klasse, gibt es nur 1x

    public double getStand() { return stand; }          // Getter
    public void setStand(double s) { stand = s; }       // Setter
    public static int getAnzahl() { return anzahl; }    // Aufruf: Konto.getAnzahl()
}
  • public und private sind Zugriffsmodifizierer (Sichtbarkeit); static sagt, wem ein Element gehört (Klasse oder Objekt).
  • Zusatzwissen: protected = eigene Klasse, Unterklassen und gleiches Paket.
5. Die Main-Methode
MerksatzDie main-Methode ist der Einstiegspunkt (Startpunkt) eines Programms: Hier beginnt die Ausführung.
public static void main(String[] args) {
    System.out.println("Hallo Welt");
}
TeilWarum?
publicDie JVM (von außen) muss die Methode aufrufen dürfen.
staticBeim Start gibt es noch kein Objekt – die JVM ruft sie über die Klasse auf.
voidKein Rückgabewert.
mainFestgelegter Name, den die JVM sucht.
String[] argsKommandozeilenparameter (Argumente beim Programmstart).
Java oder C#? In Java heißt die Methode main (klein), in C# Main (groß, static void Main(string[] args)). Das Prinzip ist identisch. Nimm die Schreibweise deiner Sprache aus dem Unterricht.
6. Compiler und Interpreter
CompilerInterpreter
ArbeitsweiseÜbersetzt den gesamten Quelltext vorabÜbersetzt und führt Zeile für Zeile zur Laufzeit aus
ErgebnisEigene Datei (Maschinencode / Bytecode)Keine eigene Ausgabedatei
GeschwindigkeitProgramm läuft meist schnellerMeist langsamer (Übersetzung bei jedem Lauf)
FehlerSyntaxfehler vor dem StartFehler erst, wenn die Zeile erreicht wird
BeispieleC, C++, Java (javac)Python, JavaScript, PHP
  • Java ist ein Mix: javac (Compiler) erzeugt aus .java den Bytecode (.class), die JVM führt ihn aus (interpretiert bzw. per JIT übersetzt).
  • Vorteil Bytecode: plattformunabhängig („write once, run anywhere“).

So füllst du einen Moodle-Lückentext sicher aus
  • Satz ganz lesen. Artikel, Zahl und Satzbau verraten, welche Wortform fehlt (Einzahl/Mehrzahl, Nomen/Verb).
  • Fachbegriff statt Umschreibung. Schreibe das Wort aus dem Unterricht. Moodle vergleicht Text – ein Synonym wird nur gewertet, wenn die Lehrkraft es als Antwort hinterlegt hat.
  • Rechtschreibung zählt. Ein Buchstabendreher macht die Lücke falsch. Dieses Quiz markiert „fast richtig“ gelb – Moodle würde es als falsch werten.
  • Groß-/Kleinschreibung: Ob sie egal ist, stellt die Lehrkraft ein. Schreib sicherheitshalber korrekt: Nomen groß (Klasse, Objekt, Compiler), Java-Wörter klein (public, static, void, main, args), Typ String groß.
  • Umlaute richtig schreiben (ä, ö, ü, ß), nicht „ae“ oder „ss“ – in diesem Quiz wird beides akzeptiert, in Moodle eventuell nicht.
  • Ein Begriff pro Lücke. Keine ganzen Sätze, keine Zusätze in Klammern, keine Leerzeichen davor oder dahinter.
  • Keine Lücke leer lassen. Eine leere Lücke bringt garantiert keinen Punkt.
  • Vor dem Abgeben alle Lücken noch einmal durchgehen und den Zeitrahmen im Blick behalten. Danach „Alles abgeben und beenden“ bestätigen.

  • Algorithmus: eindeutig, endlich, Handlungsvorschrift, Problem, Anweisungen
  • Eigenschaften: Eindeutigkeit, Endlichkeit/Terminierung, Ausführbarkeit, Determiniertheit, Determinismus, Allgemeingültigkeit
  • OOP: Klasse = Bauplan, Objekt = Instanz, Attribut, Methode, new, Konstruktor
  • Schlüsselwörter: public = überall, private = nur eigene Klasse (Kapselung), static = gehört zur Klasse
